# Utsav Singh — SDET Portfolio

A React portfolio built with Vite.

## Run locally

1. Install [Node.js](https://nodejs.org/) with npm.
2. Open a terminal in this project folder.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in the terminal. Vite normally uses `http://localhost:5173/`; if that port is already in use, it will print another port.

## Production build

Create an optimized static site:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The generated site is written to `dist/`.

## Customize

- Update page content and contact details in `src/App.jsx`.
- Update colors, layout, and responsive styles in `src/index.css`.
- Replace the portrait in `public/utsav-singh-cutout.png` if you want to use another photo.
- The resume buttons open `public/Utsav_Singh.pdf` in a new tab. Replace that file to update the resume.
